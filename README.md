# Taura Anderson – Developer Portfolio

A modern, professional software developer portfolio built with **React** and **Vite**. Showcasing skills, education, and featured projects in backend and full-stack development.

## Introduction

I'm Taura Anderson, a Software Developer specializing in backend and full-stack development. I build practical software solutions with Node.js, Express, MongoDB, Flutter, and Python. I graduated with a Bachelor of Science in Computer Science from Kibabii University, Second Class Honours (Upper Division).

## Technologies

- React
- Vite
- JavaScript
- CSS
- Framer Motion
- Lucide React

## Main Sections

- **Hero** — Introduction, call-to-action buttons, and social links
- **About Me** — Professional background and areas of interest
- **Education** — Degree and institution details
- **Technical Skills** — Skills organized by category (Frontend, Backend, Programming, Tools)
- **Projects** — Featured projects with descriptions, technologies, and GitHub links
- **Contact** — Email, GitHub, LinkedIn, and WhatsApp contact links

## Features

- Responsive design for mobile, tablet, and desktop
- Dark theme with blue accent palette
- Subtle animations and transitions
- Mobile-friendly navigation

## Local Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This project is configured for deployment on **Render Static Sites**:

- **Root Directory:** `portfolio`
- **Build Command:** `npm install && npm run build`
- **Publish Directory:** `dist`
